## 📂 Featured Projects

### Network Scanner

A Python-based network discovery and TCP port scanning tool that
identifies reachable hosts and open ports across a specified network
range.

**Engineering focus:** concurrent network operations, socket
programming, TCP/IP, and network analysis.

### File Encryptor / Decryptor

A Java utility for encrypting and decrypting files using cryptographic
operations, combining file I/O with secure data handling.

**Engineering focus:** cryptography, file I/O, data integrity, and
secure data handling.

### Multi-threaded Inventory & Trading System

A C++ application that processes customer orders concurrently while
maintaining shared inventory state.

**Engineering focus:** thread safety, concurrency, shared state,
synchronization, and team-based development.

### Car Rental System

A collaborative C# application for managing vehicle bookings, customer
records, and rental operations.

**Engineering focus:** object-oriented design, domain modelling,
collaboration, and shared-codebase development.

### Checkers

A Java implementation of the Checkers board game using object-oriented
modelling for game state, turns, and move validation.

**Engineering focus:** OOP, state management, rule validation,
algorithms, and program structure.

### Cybersecurity Analyst Path

A structured learning portfolio documenting practical development across
networking, security fundamentals, threat analysis, and security
tooling.

**Focus:** networking, security fundamentals, threat analysis, and
continuous technical development.

### Group Selection System

A Java application that automates the assignment of individuals into
groups according to defined criteria.

**Engineering focus:** algorithms, problem decomposition, input
handling, and deterministic program logic.

``` bash

```

Open the project directory:

``` bash
cd <YOUR-PORTFOLIO-REPOSITORY>
```

Then open `index.html` in a browser.

as VS Code Live Server.
